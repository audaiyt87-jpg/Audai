# حاسبة الراتب — Salary Calculator (Windows)

تطبيق سطح مكتب لويندوز يحسب الراتب النهائي بنفس معادلات ملف الإكسل.

## التشغيل مباشرة (يتطلب Python)
```
pip install customtkinter openpyxl
pythonw salary_calculator.pyw
```
امتداد `.pyw` يفتح التطبيق مباشرةً بدون نافذة سوداء (console). الواجهة مبنية بمكتبة **CustomTkinter** لمظهر احترافي عصري؛ وحزمة openpyxl مطلوبة لميزة تصدير Excel (كلتاهما تُدمجان تلقائياً داخل ملف EXE).

## بناء ملف EXE تنفيذي

### أ— على جهازك (ويندوز)
```
pip install pyinstaller customtkinter openpyxl
pyinstaller --onefile --windowed --name SalaryCalculator --collect-all customtkinter --hidden-import openpyxl salary_calculator.pyw
```
الناتج: `dist/SalaryCalculator.exe`

### ب— تلقائياً عبر GitHub Actions
1. ارفع المجلد كاملاً (مع المجلد المخفي `.github`) إلى GitHub.
2. تبويب **Actions** ← **Build Windows EXE** ← **Run workflow**.
3. بعد الانتهاء نزّل `SalaryCalculator-Windows` من قسم **Artifacts**.

## الصفحات
المدخلات في تبويب، النتائج في تبويب منفصل، وتبويب ثالث لحساب **مكافأة نهاية الخدمة**.

## مكافأة نهاية الخدمة (نظام العمل السعودي)
تبويب مستقل يحسب المكافأة حسب المادتين 84 و 85:
- **أول 5 سنوات**: نصف شهر عن كل سنة.
- **ما بعد 5 سنوات**: شهر كامل عن كل سنة، مع احتساب أجزاء السنة بالتناسب.
- **الاستقالة** (المادة 85): أقل من سنتين ← لا شيء؛ من 2–5 ← الثلث؛ من 5–10 ← الثلثان؛ 10 فأكثر ← كامل.
- **انتهاء العقد / الفصل أو الحالات الخاصة (المادة 87)**: المكافأة كاملة.

المدخلات: الأجر الشهري الأخير (مع زر لجلب الراتب من تبويب الراتب) · تاريخ الالتحاق · تاريخ انتهاء الخدمة · سبب الانتهاء. التاريخ بصيغة YYYY-MM-DD.

> ملاحظة: النتيجة تقديرية للاستئناس وليست بديلاً عن التسوية الرسمية.

## المدخلات
الشهر · الراتب الأساسي · بدل الطريق (نعم/لا + نسبة/ساعات) · بدل السكن ونوع العقد (عائلي 3 / أعزب 2) · ساعات الإضافي · السلفة · التأمين الطبي · الإجازات/الغياب/البصمات/خصميات أخرى.

## المعادلات
- الثابت = الأساسي ÷ 3
- بدل السكن = (الأساسي × عدد الأشهر) ÷ 12 (عائلي=3، أعزب=2)
- بدل الطريق: 0.07 أو 0.15 ← نسبة من (الأساسي+الثابت)؛ غير ذلك ← ساعات
- خصم السلفة والتأمين الطبي = 15% من (الأساسي+الثابت) عند أي قيمة > 0
- الصافي = الأساسي + الثابت + الطريق + السكن + الإضافي − السلفة − التأمين − الإجازات − الغياب − البصمات − خصميات أخرى

## الطباعة / حفظ PDF
- زر **طباعة / حفظ PDF**: يفتح تقريراً منسقاً في المتصفح؛ اضغط Ctrl+P ثم اختر "حفظ كـ PDF" أو اطبع مباشرة.
- زر **حفظ تقرير (HTML)**: يحفظ التقرير كملف في المكان الذي تختاره.

## التصدير إلى Excel
- زر **تصدير إلى Excel**: يضيف نتائج الشهر الحالي كـ**شيت جديد** داخل ملف الإكسل.
- اسم الشيت = **تاريخ يوم التصدير** (مثل `2026-10-11`)؛ وعند تكرار التصدير في نفس اليوم يضاف رقم تسلسلي.
- **الشيت الأحدث يتصدّر الملف** (يظهر أولاً)، وتبقى شيتات الأشهر السابقة محفوظة كما هي.
- اختر نفس الملف في كل مرة لتراكم الأشهر داخل ملف واحد.
